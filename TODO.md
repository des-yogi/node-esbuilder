## 1. Deploy на GitHub Pages

**Приоритет:** Готово (но требует уточнения... сейчас деплоит в отдельную ветку "docs", а надо в "master в папку docs")

Добавить возможность деплоя содержимого `build/` на GH Pages.

**Варианты реализации (выбрать один):**

- **А) GitHub Actions** — файл `.github/workflows/deploy.yml`, автоматический
  деплой при пуше в master.
- **Б) npm-скрипт** — `npm run deploy`, ручной деплой через `gh-pages` пакет.

## 2. Дебаунс (debounce) для вотчеров в dev-server

**Приоритет:** низкий

Сейчас при быстром сохранении нескольких файлов подряд (Ctrl+S → Ctrl+S)
каждое изменение запускает пересборку. Первое блокирует следующие через
`isRebuilding`, но последующие изменения просто **теряются**.

**Что нужно:**

- Добавить debounce (200–300 мс): при серии изменений запускать пересборку
  один раз после паузы
- Или: после завершения текущей пересборки проверять, были ли изменения
  во время неё, и если да — запустить ещё одну

## 3. Проверка на реальном проекте

**Приоритет:** В процессе.

Обкатать сборщик на небольшом реальном проекте, выявить edge-кейсы:

- Много блоков (10+)
- Bootstrap через `addCssBefore` + `copiedJs`
- SVG-спрайт
- Несколько HTML-страниц
- `singleCompiled` SCSS
- `img:opt` на реальных фотографиях
