---

## 0. Установка и запуск

- [ ] `npm i` — зависимости ставятся без ошибок
- [ ] `npm run dev` — dev-сервер стартует, браузер открывается
- [ ] `npm run build` — production-сборка завершается без ошибок
- [ ] `build/` содержит css/, js/, img/, fonts/, *.html после сборки

---

## 1. Очистка (clean.mjs)

- [ ] `npm run build` — папка `build/` полностью очищается перед сборкой
- [ ] Старые файлы от предыдущей сборки НЕ остаются

---

## 2. Создание блока (createBlock.mjs)

- [ ] `npm run create-block -- my-block` — создаёт `src/blocks/my-block/`
- [ ] Создаются файлы: `my-block.scss`, `my-block.html`, папки `img/`, `bg-img/`
- [ ] `my-block` автоматически добавлен в `projectConfig.json` → `blocks`
- [ ] `npm run create-block -- my-block js` — дополнительно создаёт `my-block.js`
- [ ] Повторный вызов НЕ перезаписывает существующие файлы
- [ ] Вызов без имени блока — выдаёт ошибку в консоль
- [ ] Содержимое `.scss` — с `@use '../../scss/variables' as *;` и шаблоном БЭМ
- [ ] Содержимое `.html` — с DEV-комментарием и `<div class="my-block">`

---

## 3. Генерация style.scss (generateStyle.mjs)

- [ ] `npm run gen:style` — генерирует `src/scss/style.scss`
- [ ] В style.scss — комментарий «не редактируйте вручную»
- [ ] addCssBefore идёт ПЕРЕД блоками с `as *`
- [ ] Блоки подключаются через `@use` в порядке ключей из `projectConfig.blocks`
- [ ] addCssAfter идёт ПОСЛЕ блоков с `as *`
- [ ] Пути преобразуются корректно (src/scss/variables → ./variables)
- [ ] Пути к блокам преобразуются (src/blocks/page/page.scss → ../blocks/page/page)

---

## 4. Компиляция стилей (styles.mjs)

### 4.1 Основной бандл

- [ ] `build/css/style.min.css` создаётся
- [ ] Dev-режим: стили в expanded-формате + `.map` файл рядом
- [ ] Production-режим: стили сжаты (compressed), без .map

### 4.2 PostCSS-плагины

- [ ] Autoprefixer работает (проверить: `display: flex` → `-webkit-` если нужно по browserslist)
- [ ] `browserslist` из `package.json` подхватывается
- [ ] Сортировка media-queries работает (мобильные-first)
- [ ] `postcss-inline-svg` работает (SVG в CSS background)
- [ ] `customPostcss.js` — если добавить плагин, он применяется

### 4.3 singleCompiled

- [ ] Добавить в конфиг: `"singleCompiled": ["src/scss/admin.scss"]`
- [ ] Создать `src/scss/admin.scss` с каким-то содержимым
- [ ] После сборки — `build/css/admin.min.css` создаётся отдельно
- [ ] `admin.min.css` НЕ попадает в `style.min.css`
- [ ] PostCSS-плагины применяются и к singleCompiled

### 4.4 copiedCss

- [ ] Файлы из `copiedCss` копируются в `build/css/` без изменений
- [ ] Проверить: `build/css/bootstrap.min.css` — идентичен исходному

### 4.5 Ошибки

- [ ] Синтаксическая ошибка в SCSS — сборка не крашится, ошибка в консоли

## 5. Сборка JS (scripts.mjs)

### 5.1 Основной бандл

- [ ] `build/js/script.min.js` создаётся
- [ ] Dev-режим: без минификации + `.map` файл
- [ ] Production-режим: минифицированный, без .map

### 5.2 Порядок файлов в бандле

- [ ] `src/js/index.js` выполняется ПЕРВЫМ (no-js → js, vh fix)
- [ ] addJsBefore → блоковые JS → addJsAfter — порядок соблюдается
- [ ] Если `src/js/index.js` указан в `addJsAfter` — НЕ дублируется

### 5.3 Блоковые JS

- [ ] JS-файлы блоков подключаются, если существуют
- [ ] Отсутствие JS-файла у блока НЕ вызывает ошибку
- [ ] JS блока выполняется корректно в итоговом бандле

### 5.4 copiedJs

- [ ] Файлы из `copiedJs` копируются в `build/js/` без обработки
- [ ] Проверить: `build/js/bootstrap.bundle.min.js` — идентичен исходному

### 5.5 npm-пакеты

- [ ] `import` из `node_modules` в JS блока — esbuild подтягивает
- [ ] CJS-пакет через `import` — работает (esbuild конвертирует)
- [ ] ESM-пакет через `import` — работает

### 5.6 Формат бандла

- [ ] Формат IIFE (не загрязняет глобальный скоуп)
- [ ] `target: es2019` — проверить: стрелочные функции сохраняются, но async generators нет

### 5.7 Функционал index.js

- [ ] `no-js` → `js` на `<html>` — работает
- [ ] `--vh` CSS-переменная устанавливается
- [ ] Lazy-load фонов (`data-bg` / `data-bg-webp`) — работает при скролле
- [ ] Theme switcher — кнопка `#toggle-theme` переключает тему
- [ ] Theme switcher — сохраняет выбор в localStorage
- [ ] Theme switcher — синхронизация между вкладками

### 5.8 Ошибки

- [ ] Синтаксическая ошибка в JS — сборка не крашится, ошибка в консоли

## 6. Сборка HTML (html.mjs)

### 6.1 Базовое

- [ ] Все `src/*.html` → `build/*.html`
- [ ] ��есколько HTML-файлов в src/ — все обрабатываются

### 6.2 @@include

- [ ] Простой `@@include('blocks/header/header.html')` — подключается
- [ ] `@@include('_include/page_head.html')` — подключается
- [ ] Вложенные @@include (include внутри include) — работают
- [ ] Пути с поддиректориями — корректно резолвятся

### 6.3 Переменные

- [ ] `@@include('...', { "title": "Привет" })` + `@@title` в шаблоне — подставляется
- [ ] Вложенные переменные: `@@user.name` → значение из `{ "user": { "name": "Иван" } }`
- [ ] `@@img.jpg` (не переменная, а часть имени файла) — НЕ ломает парсинг
- [ ] Отсутствующая переменная — заменяется на пустую строку (без ошибки)

### 6.4 DEV-комментарии

- [ ] `<!--DEV ... -->` — удаляются из итогового HTML
- [ ] `@@include` внутри DEV-комментария — НЕ обрабатывается

### 6.5 Ошибки

- [ ] Циклический include (A→B→A) — ошибка с понятным сообщением, без зависания
- [ ] Несуществующий файл в @@include — ошибка с путём файла

- [ ] Блок без `.scss` файла → предупреждение

- [ ] Кириллица в имени файла → проверить (может понадобиться)
- [ ] Пробелы в пути проекта → проверить
